RailLCA
Excel Add-in — served from GitHub Pages · No local server needed
📋 Project LC 🗂 Project Definition ⚡ Project Input
1

Download the package

Download rail-lca-github.zip from the repository's Releases page and unzip it to a permanent folder on your computer, e.g. C:\Rail-LCA-Addin\.

2

Edit manifest.xml

Open manifest.xml in Notepad and replace YOUR-USERNAME and YOUR-REPO with your actual GitHub username and repository name everywhere they appear.

3

Register with Excel

Double-click INSTALL-ADDIN.bat (run as administrator if it fails). This writes the manifest path into the Windows registry so Excel finds it. You only do this once.

4

Open Rail-LCA.xlsx in Excel

You will see a new "Rail-LCA" tab appear in the Excel ribbon. No server needed — the task pane loads directly from this GitHub Pages URL.

5

Click a ribbon button → use the task pane

Each button opens a side panel for that sheet. Click ↓ Read Excel to load data, edit your fields or table rows, then click 💾 Save to Excel. Changes write directly into your open .xlsx file — no download or copy-paste needed.

The add-in uses the Office.js Excel API to read and write directly to worksheet cells.
All three input sheets (Project LC, Project Definition, Project Input) support full Create / Read / Update / Delete.
Dropdowns are auto-populated from your Component Library and Equipment Gang Library sheets.
